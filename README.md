# Codebase for reproducing empirical findings in ``A mathematical theory of balancing relational generalization and memorization''

- ``sports_hierarchy_finetuning.py'' contains the script for running all experiments describe in Appendix C/Section 5.
- The three bash scripts can be deployed on a Slurm cluster.
- ``collate_results.py'' collates the results
- ``make_main_figure.py'' creates the main figure.
